# CA Kangana Sharma - Virtual CFO & Financial Advisory Website

A modern, responsive, multi-page personal brand website built for **CA Kangana Sharma**, Chartered Accountant, Virtual CFO, and Tax Strategist based in New Delhi, India.

## 🚀 Features

- **Responsive Multi-Page Design**: Clean design built with vanilla HTML5, CSS3, and JavaScript.
- **WhatsApp Direct Integration**: Quick CTA buttons linking straight to WhatsApp for consultation inquiries.
- **Pages**:
  - `index.html`: Hero, Service Highlights, Interactive Pricing Calculator, Testimonials.
  - `services.html`: Detailed breakdown of Virtual CFO, GST Compliance, Tax Advisory, and Statutory Audit services.
  - `about.html`: Professional bio, career timeline, key credentials, and core values.
  - `blog.html`: Latest insights, regulatory updates, tax guides, and newsletter subscription.
  - `contact.html`: Consultation booking form, office locations, pre-filled WhatsApp action buttons, and FAQ accordion.

## 🛠️ Setup & Running Locally

Simply serve the files using any standard HTTP server (or open `index.html` directly in your browser):

```bash
# Using Python
python -m http.server 8000

# Or using Node.js npx
npx serve .
```

## 🎨 Tech Stack

- **HTML5** & **Vanilla CSS3** (Custom properties/CSS variables, flexbox, grid)
- **JavaScript (ES6+)** (Dynamic navbar scrolling, active state indicators, interactive accordions)
- **Lucide Icons**
- **Google Fonts** (`Plus Jakarta Sans`)
